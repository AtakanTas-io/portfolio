# Atakan Taş — Portfolio

Source code for my personal portfolio website.

**Live site:** https://tasatakan.netlify.app/

The website presents my Computer Science background, selected projects and contact links in a developer-oriented interface.

## Stack

- HTML
- CSS
- JavaScript
- Netlify

## Repository structure

- `index.html` — home page
- `hakkinda.html` — about page
- `portfolyo.html` — projects page
- `hobiler.html` — interests page
- `iletisim.html` — contact page
- `style.css` — shared styles
- `script.js` — shared client-side behavior
- `netlify.toml` — Netlify configuration
- `robots.txt` and `sitemap.xml` — search-engine metadata

## Current focus

The portfolio is being aligned with my current technical focus: Python development, network automation, cybersecurity fundamentals and backend engineering, with NetMon as the primary project.

Project descriptions should reflect what is implemented in the linked repositories rather than planned or experimental capabilities.
